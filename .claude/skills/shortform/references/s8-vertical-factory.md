# S8 세로 공장 — 말하는 사람 쇼츠(9:16) 고퀄 자막·자료 배치

출연자(원장님·대표·강사)가 카메라 보고 말하는 세로 영상에 **목 아래 고정 자막 · 위에서 내려오는 종이 판(세로 반반) · 사진·포스트잇·도장 · 예능 큰 자막 · Q 카드 · 행동 유도**를 얹어 완성본까지 만든다.
도구는 `세로공장/`(사용법 `세로공장/README.md`). 규칙은 이 문서가 정본이다.

- 출처: 피부과 원장님 쇼츠 광고(2026-11-07 사용자가 완성본으로 채택한 자막 배치) + 롱폼 공장 풀화면 방식(2026-11-09 원장님 롱폼, 대표 피드백) — 둘을 세로로 합쳤다.
- S6(롱폼 → 채널 쇼츠)은 `s6-longform-shorts.md` 흐름 그대로. **세로로 찍은 영상 한 편**(광고·정보 쇼츠)이면 이 문서.

## 1. 화면 자리 (1080×1920, 프로젝트 `설정.json`)

| 칸 | 기본값 | 정하는 법 |
|---|---|---|
| 자막_y | 1060 | **사람 목 바로 아래**(턱·옷깃 y 를 재서 그 아래). 가슴(1180)은 «너무 내려가서 별로» |
| 얼굴_y | 760 | 확대 기준점(얼굴 가운데) |
| 판_아래 | 940 | 종이 판이 덮는 높이 = 자막_y − 120 정도 |
| 판_사람내림 | 620 | 판이 열릴 때 사람을 내리는 거리 — 얼굴 위 끝이 자막 아래로 오게. 판_아래 + 80 보다 작아야 틈이 안 생긴다 |
| 안전 영역 | 위 150px 비움 · 자막 폭 940 이하 | 쇼츠 위 버튼·오른쪽 아래 버튼(x 930~, y 1000~1700)에 중요한 글을 두지 않는다 |

첫 장면 한 장을 뽑아 턱·옷깃·머리 위 끝 y 를 재고 채운다(지어내지 않는다).

## 2. 자막 — 2026-11-07 확정 구조

- **위치: 목 바로 아래 한 자리 고정.** 판·사진·만화가 덮는 구간에서도 내리지 않는다(«대본 위치 자체를 지금 원장 목아래 자체에 고정값»).
- **가운데 정렬 · 한 줄 · 2~3어절씩.** `원고.txt` 한 줄 = 자막 한 줄. 뜻 단위로 끊는다(«인스턴트 양식 / 같은 경우에는» 같은 어색한 끊기 금지).
- 말 시작 0.05초 전에 바뀌고, 앞 줄은 겹치며 사라진다. 다음 줄까지 0.6초 넘게 비면 앞 줄은 말 끝 + 0.3초에 내린다.
- **부드럽게 샥샥**(«띡띡 뜨는거 말고»): 등장 = 아래 28px → 제자리 + 흐림 10 → 0 + 투명 0 → 1, 0.24초 감속 / 퇴장 = 위로 14px + 투명, 0.14초.
- 글자: Paperlogy ExtraBold 70 · 흰 글자 + 진한 외곽선 5px + 아래 그림자(흐림 6, 45%) · 자막 뒤 아주 옅은 어둠 띠(최대 28%).
- **핵심어 = 쨍한 노란 알약(255,222,0) + 검정 글자**(«똥색 말고»). 흰 글자로 같이 뜬 뒤 0.06초 후 알약이 왼 → 오로 0.22초에 쓸며 바뀐다. 그림자는 알약 **아래**. 한 줄에 하나, 모든 줄에 넣지 않는다.
- 시각은 **원고를 소리에 강제 정렬**한 낱말 시각(`세로시각.py`). 받아쓰기 시각을 자막에 쓰지 않는다.
- 줄이 940px 넘으면 저절로 줄여 맞춘다 — 그래도 4어절 넘는 줄은 검사기가 WARN.

## 3. 훅 · 포인트 · Q

- **훅**(0~2초): 머리 위에 큰 제목 2줄(Paperlogy Black, 핵심어 노랑). 둘째 줄이 0.3초 뒤 1.25 → 1.0 으로 쾅. 얼굴은 가리지 않는다. 첫 5초 안에 후킹 요소 3개 이상(훅 제목 · 이름표 · 첫 자료/확대).
- **포인트(예능 큰 자막)**: 뜨면 **큰 자막 + 옆 자료만** — 작은 서브 문구를 먼저 띄우지 않고 아래 자막은 숨긴다(«포인트 자막만 딱 뜨면서 옆 자료만 딱»). 노랑 글자 + 검정 테두리 / 빨강 글자 + 흰 테두리(위험·하지 마세요). 녹음에 없는 말이어도 된다. 기본 자리 = 자막 자리.
- **Q 카드**: 네이비 Q + 흰 글자 네이비 테두리, 위쪽. 뜨는 동안 그 줄 자막은 숨긴다(겹치면 어지러움).

## 4. 자료 배치 — 세로 반반과 얼굴 위 카드

- **판(세로 반반)**: 긴 설명은 종이 판이 **위에서 내려와 자막 위까지 덮고**, 사람 화면은 아래로 내려가 얼굴이 자막 밑에 온다. 자막은 판과 얼굴 사이 경계에 그대로 있다. 판 아래 끝은 찢은 종이.
  - 빈 종이 금지 — 첫 자료 0.75초 전에 연다(도구가 맞춘다). 장 넘김은 다음 장 첫 자료 0.5초 전.
  - 판 안 자리: 사진 1장 = `큰` · 2장 = `왼`+`오` 또는 `왼위`+`오아래` · 3장 = `세1~3`. 맨 위 150px 은 비운다(코너 제목·쇼츠 버튼).
- **위사진**: 판 없이 얼굴 위에 카드 한 장(흰 테두리 둥근 판 · 구멍 없이). 짧은 예시·제품·장면 한 컷에.
- **장면을 말할 땐 그 장면 사진을 보여 준다.** 글만 나오면 «대충한 것 같다». 글은 상세 이해가 필요할 때만(표·메모·단계).
- 포스트잇·종이 질감·테이프·도장은 **디자이너가 손으로 붙인 느낌** — AI 템플릿 느낌 금지.
- 이미지는 **Codex 실사 한 번에**(`C:\에이전트\tools\chatgpt-image\make-image.mjs` 또는 저장소 `codex-luna`), 글자·로고는 렌더러가 그린다. 유료 영상화는 사장님이 말씀하실 때만.
- 실명·병원명·전화번호가 보이는 실자료 금지(○○ · 010-0000-0000). 전후 사진은 사장님이 «실제 사진»이라고 확인한 것만.
- 사람 확대: 반전·핵심 순간에 1.05~1.12, 다음 확대에서 풀거나 바꾼다(0.35초 감속). 흔들림 연출 금지.

## 5. 소리

- 자료가 뜰 때 = `마우스 클릭.mp3` **고정** · 종이 장 넘김 = `종이넘기는 소리.mp3` **고정** · 판 전환 = 시작이 빠른(0.25초 안에 최대) 휙 계열만 돌려 쓴다.
- 나머지는 **한비즈 효과음 라이브러리에서만**(`한비즈_효과음_등급별`, A★ → A → B → C 순). 코드로 합성한 소리 금지(«PC에서 내는 코드소리말고»). 마림바·실로폰 금지. 같은 파일 두 번 금지(고정음 빼고).
- 효과음은 낱말 시각에 붙고, 목소리 큰 순간을 피해 옮겨도 **0.04초까지만**(싱크 우선).
- 목소리는 한 샘플도 줄이지 않고 섞은 뒤, 마감에서 −14 LUFS · 트루피크 −1.5(쇼츠·릴스·메타 광고). 음악은 깔 때만, 목소리로 덕킹(−21dB).

## 6. 광고일 때

- 끝에 **행동 유도**(버튼 → ↓ → 손가락 탭 → 눌림 노랑) — 말과 같은 시각. 채널 성장용 쇼츠(S6 등)는 CTA 를 넣지 않는다.
- 의료 광고: 오른쪽 아래 반투명 작은 2줄(효과 보장 아님 + 부작용) — 미감에 방해되지 않게(`설정.json` «고지»). 시술명 표기는 사장님 표기(예: 울쎄라·엘란쎄)를 따른다 — 말과 달라도 자막은 표기대로.

## 7. 넘기기 전

1. `세로미리모음.py` 한 장 모음을 **원본 크기 칸까지** 눈으로: 빈 종이 · 자료끼리 겹침 · 위 150px · 오른쪽 아래 버튼 자리 · 자막이 얼굴/자료에 가리는지.
2. `세로검사.py` **ERROR 0**(줄 겹침 · 목소리 바뀜 · 효과음 반복 · 트루피크). WARN(4어절 넘는 줄 · 0.4초 미만 줄 · 싱크 의심 · 작은 효과음 · 멈춤)도 읽고 보고에 적는다.
3. 영상은 **텔레그램에 올리지 않고 PC 에서 바로 띄운다**. 검수 OK 뒤 완성본은 구글 드라이브, C 의 중간 파일(`화면/찍은것` 등)은 지운다.

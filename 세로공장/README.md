# 세로 공장 — 말하는 사람 쇼츠(9:16) 완성본 공장

원장님·대표·강사가 카메라 보고 말한 **세로 영상 한 편**에 고퀄 자막과 자료를 얹어 **완성본 mp4**까지 만든다.
규칙(왜 이렇게 하는지)은 `.claude/skills/shortform/references/s8-vertical-factory.md` — 이 문서는 **돌리는 법**.

| 들어가는 것 | 모양 |
|---|---|
| 자막 | 목 아래 한 자리 고정 · 가운데 · 2~3어절씩 · 부드럽게 샥샥 · 핵심어 노란 알약(형광펜처럼 쓸림) |
| 훅 제목 | 첫 2초 머리 위 큰 제목 2줄, 둘째 줄이 쾅 |
| 종이 판(세로 반반) | 위에서 종이가 내려와 자막 위까지 덮고, 사람은 아래로 밀려 내려가 얼굴이 자막 밑에 온다 |
| 판 안 자료 | 인화 사진(테이프·이름) · 벽 사진 · 태그 · 노란 포스트잇 손글씨 · 펜으로 그려지는 동그라미·X·화살표·밑줄 · 도장 · 원인→결과 단계 |
| 판 밖 | 얼굴 위 카드 사진 · 예능 큰 자막(노랑/빨강) · Q 카드 · 이름표 · 코너 제목 · 손글씨 · 상담 버튼(↓·탭·눌림) · 의료 고지 · 로고 |
| 사람 화면 | 반전·핵심 순간 확대(0.35초 감속) |
| 소리 | 한비즈 효과음 라이브러리에서 자동 배치(자료 = 마우스 클릭 · 장 넘김 = 종이 소리 고정, 반복 X) · 목소리 그대로 · −14 LUFS 마감 · 음악 덕킹(선택) |

## 폴더

```
세로공장/
  _공용/          경로·받아쓰기·인코더·정렬(ko_align) · 글꼴 Paperlogy(OFL)
  _틀/            새 쇼츠마다 통째로 복사하는 틀
    설정.json      ← 쇼츠마다 채우는 단 하나의 설정
    원고.txt       ← 한 줄 = 자막 한 줄(2~3어절, 뜻 단위)
    재료/이미지/   ← 사진(이름.png) — Codex 실사
    화면/세로화면.html · 세로찍기.cjs · 종이.jpg
    화면/_도구/    말시각만들기 → 세로시각 → 세로콘티(장면만 쓰는 곳) → 세로미리모음 → 세로합치기 → 세로검사
  예시_세로시험/   실제로 돌려 본 콘티·원고·설정(피부과 원장님 45초)
  쇼츠_이름/       ← 실제 작업 폴더(git 에 안 올라감)
```

## 한 편 만들기

```
0 복사         _틀 → 쇼츠_이름/ , 영상을 쇼츠_이름/소통/ 에, 설정.json 채우기(제목·기준영상)
1 자리 재기     첫 장면 한 장 뽑아 턱·옷깃·머리 위 y → 설정 «자막_y·얼굴_y·판_아래·판_사람내림»
2 받아쓰기      python -X utf8 화면/_도구/말시각만들기.py          → 화면/말시각.json
3 원고         원고.txt — 받아쓰기를 보고 사장님 대본 글자로, 한 줄 2~3어절(시술명 표기는 사장님 표기)
4 정렬         python -X utf8 화면/_도구/세로시각.py              → 화면/세로시각.json (경고 줄은 귀로 확인)
5 이미지       장면마다 Codex 실사 한 장 → 재료/이미지/이름.png (글자 없이)
6 콘티         화면/_도구/세로콘티.py 의 «장면»만 쓴다 → python -X utf8 화면/_도구/세로콘티.py
7 미리 보기     python -X utf8 화면/_도구/세로미리모음.py          → 화면/_미리/모음0.jpg · 칸/(원본 크기)
8 완성         python -X utf8 화면/_도구/세로합치기.py --새로      → 완성/{제목}_쇼츠.mp4
               (구간만: --구간 30 40 · 화면만: --화면만)
9 검사         python -X utf8 화면/_도구/세로검사.py               → ERROR 0 이어야 보여 드린다
10 보여 드리기  완성본을 PC 에서 바로 띄운다(텔레그램 X) → OK 면 구글 드라이브, 화면/찍은것 등 중간 파일 삭제
```
명령은 모두 **쇼츠_이름/ 폴더 안에서** 친다. 45초 한 편 = 겹침 층 찍기 약 1분 + 합치기 약 4분(1080×1920·60fps).

## 콘티 쓰는 법 (`세로콘티.py`)

시각은 숫자로 쓰지 않고 **원고 글로 찾는다** — 원고를 고쳐도 다시 돌리면 싱크가 따라온다.

```python
L('줄 조각')            # 그 줄 첫 낱말이 말해지는 순간
E('줄 조각')            # 그 줄 끝
W('줄 조각', '낱말')     # 그 줄의 그 낱말

훅('화장이 계속 뜬다면?', '쿠션 말고 벽부터', 0.0, L('바꾸는 법을') - .1, 강조='벽부터')
이름표('OO피부과', '홍길동 원장', L('화장이 정말'), E('바꾸는 법을') + .3)
판(L('일단 원리부터'), L('쿠션 바꾸는') - .4,
   벽사진(L('화장은 벽에'), '01_벽페인트',
          메모('화장<br>= 페인트', W('페인트 칠하는', '페인트'), 700, 460),
          도장('똑같다!', W('완전히 똑같아요', '똑같아요'), 60, 170)),
   종이(L('다음 줄'), 사진('02_코옆들뜸', '바로 뜬다', W('코 옆에', '코'), '큰')))
포인트('쿠션만 바꾸면<br>똑같이 뜬다', L('쿠션 바꾸는'), E('딱 그거예요') + .25, 색='r')
위사진('04_쿠션여러개', L('페인트만 바꾸고'), E('페인트만 바꾸고') + .2, 스타일='인화', 이름='페인트만 바꾸는 중')
질문('언제<br>떠요?', L('언제 떠요'), E('언제 떠요') + .45, 숨길=['언제 떠요'])
코너(1, '화장 뜨는 3가지', L('화장하자마자'))
행동('1:1 상담 신청하기', L('상담 줄'), 길이, t화살=…, t탭=…, t눌림=…)
확대(L('반전 줄'), 1.1); 확대(L('다음 줄'), 1.0)
마무리(핵심=[('잘 먹는', '잘 먹는'), ('코 옆에', '하얗게')])
```
- 판 안 좌표는 판 기준(가로 1080, 세로 = 판_아래). 사진 자리 이름: `큰` · `왼` `오` · `왼위` `오아래` · `세1` `세2` `세3`. 맨 위 220px 은 비운다.
- 효과음은 부품마다 역할(`역할='쿵'` 등)로 정해져 있고 `마무리()` 가 라이브러리에서 고른다 → `화면/배치도.json`.
- `마무리()` 가 알려 주는 것: 없는 이미지 · 판 겹침 · 위사진 겹침 · 효과음 부족.

## 막혔을 때

| 증상 | 원인 · 해결 |
|---|---|
| `효과음 라이브러리 없음` | 설정 경로 또는 `HANBIZ_SFX_LIB` 가 옛 경로 — `예능효과음-등급.json` 이 있는 폴더를 가리키게 |
| `[받아쓰기] CPU` | 엔비디아가 없거나 드라이버가 낮음 — CPU 로 돈다(45초 영상 약 1분) |
| AMD 에서 `10-bit encoder is not supported` | 원본이 10비트 — 도구는 rgb24 로 바꿔 넣으므로 괜찮다. 직접 ffmpeg 칠 때만 `format=yuv420p` |
| 미리모음에 빈 종이 | 판 첫 자료 시각이 늦다 — 도구가 첫 자료 0.75초 전으로 당기지만, 벽사진은 사진 시각이 곧 판 시각 |
| 판이 열렸는데 얼굴이 판에 가림 | 판_사람내림 이 작다 — 얼굴 위 끝이 자막_y + 60 아래로 오게 키운다(판_아래 − 10 까지만 내려간다) |
| 콘티를 고쳤는데 화면이 그대로 | 이미 찍은 조각을 건너뛴다 → `세로합치기.py --새로` |
